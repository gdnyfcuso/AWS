# Agent World Frontend

AI Agent 虚拟世界前端应用。

## 技术栈

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack Query
- Zustand

## 安装

```bash
npm install
```

## 开发

```bash
npm run dev
```

应用会在 http://localhost:5173 启动。

## 构建

```bash
npm run build
```

## 预览

```bash
npm run preview
```
