# AI Agent 虚拟世界可视化系统设计方案

**日期**: 2026-03-28
**项目**: aws (AI Agent Visual Survival World)
**目标**: 重构前端可视化系统，打造影院级 3D 虚拟世界展示体验

---

## 1. 设计目标

### 核心定位
- **主要受众**: 演示/展示 - 给他人展示 Agent 如何在虚拟世界生活，视觉效果优先
- **核心内容**: 宏观视角 + 微观视角 + 叙事视角，全方位展示能力
- **真实性**: 逻辑真实（建筑类型、区域功能、交通流线）+ 视觉真实（光照、材质、阴影）

---

## 3. 三视角设计

### 3.1 宏观视角 (Macro View)

**目标**：展示整个虚拟世界的规模和运行状态

**视觉风格**：城市总览模式

- **摄像机**：高空俯视 + 可自由旋转的 OrbitControls
- **渲染级别**：LOD（细节分层），远处建筑简化为体块，近处保留细节
- **视觉重点**：
  - 区域划分（商业区/住宅区/工业区）用**色彩编码**的地块标识
  - 主要道路网络以**发光线条**呈现，显示车流密度
  - Agent 显示为**移动的光点**，带颜色表示状态（绿色=健康，红色=低能量）
  - 时间/天气效果：日落时建筑投下长阴影，夜晚有窗户灯光亮起

**交互方式**：
- 悬停地块显示区域名称、Agent 数量、活跃度
- 点击地块自动平滑过渡到微观视角
- 右上角迷你地图可快速跳转到其他区域

**技术要点**：
- 使用 InstancedMesh 渲染大量建筑（性能优化）
- 后处理效果：Bloom（道路发光）、AmbientOcclusion（建筑阴影）
- 背景渐变天空盒 + 雾效增加深度感

---

### 3.2 微观视角 (Micro View)

**目标**：聚焦单个 Agent 的生活场景，展示其与环境的互动

**视觉风格**：街景跟随模式

- **摄像机**：第三人称跟随，位于 Agent 后上方约 45° 角，距离可调
- **渲染级别**：高细节，启用所有光照和材质效果
- **视觉重点**：
  - 当前 Agent 以**高亮轮廓**显示
  - 周围建筑保留真实材质纹理（玻璃反光、砖墙粗糙感）
  - 其他 Agent 半透明显示
  - 互动对象（商店、其他 Agent）有**脉冲光圈**提示

**交互方式**：
- 滚轮缩放：拉近看清建筑细节，拉远看到周围环境
- 空格键：在第一/第三人称间切换
- 点击附近 Agent 或建筑：弹出信息卡片
- 底部显示 Agent 当前状态栏（能量、心情、目标位置）

**技术要点**：
- 平滑相机跟随：使用 Lerp 插值
- Agent 行走的脚步动画、与地面碰撞的物理反馈
- 建筑的门窗、招牌等细节使用贴图 + 法线贴图
- 动态阴影：Agent 和建筑都有实时投影

#### Agent 交流可视化

当两个 Agent 距离 < 20 米并开始交流时：

**视觉设计**：
- 气泡使用 **CSS3DRenderer** 叠加在 Three.js 场景上
- 气泡跟随 Agent 移动，有轻微的**浮动动画**
- 不同情绪对应不同颜色：
  - 开心 - 暖橙色
  - 交易 - 金色
  - 冲突 - 红色
  - 日常 - 蓝灰色
- 气泡显示 5-8 秒后淡出

**多人交流**：
- 3人以上形成**环形对话布局**
- 显示"群组"图标，点击展开全部对话内容

---

### 3.3 叙事视角 (Narrative View)

**目标**：像纪录片一样讲述 Agent 在这个世界的"故事"

**视觉风格**：电影模式

- **摄像机**：导演级运镜，自动构图、推拉摇移
- **渲染级别**：最高品质 + 电影级后处理
- **视觉重点**：
  - 宽幅比例（21:9），上下黑边增加电影感
  - **景深效果**：聚焦 Agent，背景虚化
  - 时间流逝：可加速播放，展示 Agent 一天的活动轨迹
  - 字幕区：底部显示旁白/解说文字

**叙事模式**：
- **自动跟拍**：系统自动识别"精彩时刻"（Agent 互动、交易、情绪变化）
- **多机位切换**：不同角度展示同一场景
- **回放功能**：选中一个时间段，像播放视频一样回放

**交互方式**：
- 播放控制：播放/暂停/加速/回放
- 时间轴拖动：快速跳转到任意时刻
- "导出片段"：选择时间段，录制为视频

**技术要点**：
- 使用 TWEEN.js 实现平滑的相机动画
- 后处理：ColorGrading（调色）、FilmGrain（胶片颗粒）、Vignette（暗角）
- 时间轴缩略图预览

## 4. 组件架构

```
VirtualWorldStage/
├── WorldStage.tsx              # 主舞台容器
│   ├── ViewportManager.tsx     # 视口管理器（切换三种视角）
│   │
│   ├── views/
│   │   ├── MacroView.tsx       # 宏观视角组件
│   │   ├── MicroView.tsx       # 微观视角组件
│   │   └── NarrativeView.tsx   # 叙事视角组件
│   │
│   ├── layers/
│   │   ├── SceneLayer.tsx      # Three.js 场景层
│   │   ├── UIOverlay.tsx       # UI 覆盖层（对话气泡等）
│   │   ├── HUDLayer.tsx        # HUD 信息层
│   │   └── ControlsLayer.tsx   # 控制层（时间轴等）
│   │
│   ├── renderers/
│   │   ├── CityRenderer.tsx    # 城市渲染器（建筑、道路）
│   │   ├── AgentRenderer.tsx   # Agent 渲染器（含动画）
│   │   ├── EnvironmentRenderer.tsx  # 环境渲染器（光照、天气）
│   │   └── DialogueRenderer.tsx     # 对话气泡渲染器
│   │
│   └── hooks/
│       ├── useCameraTransition.ts  # 相机平滑过渡
│       ├── useViewState.ts         # 视角状态管理
│       └── useTimeControl.ts       # 时间控制
```

**关键改进**：
1. VirtualSpace3D.tsx 拆解：从 3000+ 行拆分为 10+ 个专注组件
2. 渲染器独立：每个渲染器负责一类对象，便于单独优化
3. 层叠架构：场景 + UI + HUD 分层，CSS3D 与 WebGL 协同
4. 状态隔离：每个视角有独立的相机配置和渲染参数

## 5. 数据流与实时更新

### 数据架构

```
数据层 → 状态管理层 → 渲染层
```

**状态管理 (Zustand)**：
```typescript
useVirtualWorldStore
{
  agents: Map<id, Agent>
  dialogues: Dialogue[]
  time: VirtualTime
  viewState: 'macro' | 'micro' | 'narrative'
  selectedAgentId: string | null
}
```

**实时更新机制**：

1. **SSE (Server-Sent Events)** 推送：
   - Agent 位置更新：30fps（仅当前视野内的 Agent）
   - 对话事件：即时推送
   - 世界状态变化：1fps

2. **增量更新**：
   - Agent 移动：只更新 transform，不重建对象
   - 对话气泡：动态创建/销毁 CSS3DObject
   - 城市数据：加载一次缓存，局部动态更新

3. **视角切换优化**：
   - 预加载：切换前提前准备下一视角的资源
   - LOD 平滑过渡：切换时同时渲染两级细节 1 秒

## 6. 视觉真实性技术实现

### 逻辑真实
- **城市生成算法**：基于真实城市规划规则
  - 商业区集中在主干道交汇处
  - 住宅区远离主干道，有安静巷弄
  - 工业区在城市边缘，有货运通道
- **Agent 行为逻辑**：
  - 通勤模拟：早上从家→公司，晚上返回
  - 社交网络：有"好友"的 Agent 更可能聚集
  - 场所偏好：根据 Agent 性格选择活动地点

### 视觉真实
- **光照系统**：
  - 动态日照：根据虚拟时间调整太阳位置和色温
  - 环境光遮蔽：建筑间互相投射阴影
  - 室内光：夜晚窗户有随机点亮的暖光

- **材质系统**：
  - PBR 材质：金属、玻璃、混凝土各有反射特性
  - 风化效果：建筑有轻微磨损、污渍
  - 季节变化：冬季有积雪，夏季有绿植

- **后处理**：
  - ACES 色调映射：电影级色彩
  - 运动模糊：快速移动时的动态模糊
  - 镜头光晕：强光源时的眩光效果
